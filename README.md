# Aventura da Letra V

Joguinho educativo feito com React + Vite.

## Como executar no computador

1. Instale o Node.js.
2. Abra a pasta do projeto no VS Code.
3. No terminal, execute `npm install`.
4. Depois execute `npm run dev`.
5. Abra o endereço local indicado pelo Vite.

## Como publicar no Vercel

1. Envie todos os arquivos desta pasta para um repositório no GitHub.
2. Entre no Vercel e escolha **Add New > Project**.
3. Importe o repositório.
4. O Vercel identifica o Vite automaticamente.
5. Clique em **Deploy**.

Comando de build: `npm run build`  
Pasta de saída: `dist`
